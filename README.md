# Admin Dashboard

A dashboard interface built with HTML and CSS as part of The Odin Project curriculum. This project focuses on mastering CSS Grid, creating nested layouts, and organizing complex page structures into reusable sections.

**Features:**
- Sidebar navigation
- Search bar and user profile header
- Responsive project card grid
- Announcements and trending sections

**Technologies:** HTML5, CSS3, CSS Grid

[You can see it here](https://woodheadbear.github.io/dashboard-template/)
